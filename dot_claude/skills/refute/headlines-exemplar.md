# Headlines exemplar

The step-6 report of a `/refute` run, as its reader wants it: skimmed in a terminal to learn how the change fared and what is left to decide. Match the example below. The reasons under it are what let the shape bend to a run the example does not cover.

## Example

A run on one drafted change, a new bullet for a quiz skill, with its real values.

<example>

```markdown
| | Headlines |
|---|---|
| 🧪 Refuted | 1 change, 1 with an objection that held |
| 🤔 For you | 1 decision: I'd drop the bullet |
| 🪙 Tokens | 358.8k |

| # | Change | Strongest objection | Fix |
|---|---|---|---|
| 1 | "A process is asked as a trace" bullet | A partial trace has no pass mark: the skill scores a fuzzy answer **wrong** and also says to coax a correct one-liner for free, and the bullet doesn't say which applies. All three refuters hit this independently | Drop |

**Footnotes**
- **Already covered:** the skill's single open coax ("and the machinery?") recovers a compressed answer in one turn. Today's four turns came from my double question, which is a miss against rules that already exist.
- **Reach:** by one refuter's reading, about 17 of the 152 entries in play are process-shaped, so the bullet would matter in roughly one sitting in 12 to 18.
- **If kept:** two more objections held and would need fixing first. A "concrete case" tends to give the answer away (a cold-written opener leaked the small-side facet through its row counts), and "start to finish" collides with one facet per turn.
```

</example>

## Why it looks like this

- **The For you row carries the lean.** The run ends on the reader's decision, so the row counts the decisions waiting and says which way the run leans where it has a view: a reader who trusts the review in place of reading the prose needs the recommendation before the evidence.
- **Each row holds one change and its strongest objection.** Further objections that held are counted in one footnote, since they matter only if the reader keeps the change against the strongest one.
- **A footnote passes the "so what?" test: the reader would decide differently for knowing it.** The three here each bear on the one decision: what already does the job, how often the change would matter, and what keeping it would take. Which refuter said what, what each read and what survived all fail it.
- **The values follow the run.** A run on several changes has a row for each that drew an objection that held, a fix is as often a reword or a move as a drop, and a run where every change survived is the Headlines table alone.
